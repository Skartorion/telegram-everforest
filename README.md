# 🌲 Everforest Medium Dark theme for Telegram Desktop

[![Telegram Theme](https://img.shields.io/badge/Telegram-Theme-blue?logo=telegram)](https://t.me/addtheme/everforestdarkmedium)
[![License: MIT](https://img.shields.io/badge/License-MIT-green)](LICENSE)

### Guide
1. Open the [theme link](https://t.me/addtheme/everforestdarkmedium) in Telegram Desktop and apply the theme.
2. Or, download the [`everforest-dark-medium.tdesktop-theme`](everforest-dark-medium.tdesktop-theme) file from this repo and import it inside the app.
3. Star the repo if you liked the theme.
